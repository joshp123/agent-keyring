Set it up

Paste one prompt into Claude Code or Codex. Your agent downloads the Mac app, tells you what it suggests next, and asks before touching anything.

Install and set up Agent Keyring using https://keyring.opentrawl.sh/llms.txt. Tell me what you plan to do and ask before scanning my network or changing anything.
  1. 1

    Paste the prompt (or download the Mac app)

    Paste the prompt above into Claude Code or Codex, or download the signed Mac app yourself from GitHub Releases (macOS 26 or later). Your agent verifies the checksum, installs it in /Applications, and asks before changing anything else.

  2. 2

    Copy your passwords from Apple Passwords

    In Apple Passwords, choose File > Export All Items to App… and pick Agent Keyring. Nothing is deleted from Passwords, and every password starts on Ask so no agent gets one until you approve.

  3. 3

    Let your agent wire up the rest (with your say-so)

    Your agent reads agent-keyring skill, tells you what it recommends, and asks before touching your Chrome-family browser extension, enrolling Linux or Mac servers, or connecting your iPhone and Apple Watch (join the TestFlight beta or build from source).

Each password has a rule

Every password starts on Ask. Change the rule whenever you like.

Ask

An agent has to ask, and you approve or deny. One approval covers that one password for that one task, 30 minutes at most.

Automatic

Agents on the computers you choose get it without asking. Use it for a password you’d leave on that computer anyway, like the one for a staging site.

Blocked

Once a computer receives the rule, it refuses every request. Good for your bank and your email.

How it works

Your agent runs a command, agent-keyring, and asks for one password by website. You see the website, the account, which agent on which computer is asking, and its reason. Approve, and Agent Keyring signs in for that task. There’s no cloud vault and no account: your passwords stay encrypted on your own devices.

Your passwords are encrypted on your own devices

Your Mac and iPhone encrypt their approval copies with keys kept in the Secure Enclave, the chip behind Touch ID and Face ID. Those keys can’t leave the chip. A computer allowed to use an Automatic password keeps a copy it can open itself.

Works in any browser, app or CLI

You just approve the request; your agent picks the right way to sign in. When it’s in Chrome, Brave, Edge, Arc or Chromium with the extension loaded, the extension types the password straight into the form. In Safari, built-in agent browsers, desktop apps (via computer use) or CLI tools, your agent passes the approved password straight into the tool or app.

One approval, one password, one task

An approval covers retries and ends when the agent releases it, when the computer receives your Stop, or after 30 minutes at most.

Two-factor codes work too

If you set up a site’s two-factor code in Apple Passwords, Agent Keyring fills it in along with the password. For an Ask password, your agent never gets the setup key, so it can’t make codes of its own later.

Already use Apple Passwords?

Then you don’t need a second password manager, a new account or a subscription.

Questions

Does my Mac have to stay awake?

No. Your iPhone keeps its own encrypted copy of your passwords, and an agent on another computer sends its request straight to your iPhone and Apple Watch. That agent can sign in while your MacBook is shut in a bag.

Do I need Tailscale?

Not on one Mac. You need it to approve from your iPhone or Apple Watch, and for agents on other computers. The free plan is enough.

Does it work in Safari, desktop apps, or the browsers built into Codex, Claude and T3 Code?

Yes. You approve once, and your agent handles how to sign in: using the browser extension in Chrome-family browsers, or passing the approved password straight into Safari, built-in agent browsers, desktop apps via computer use, or CLI tools.

What is the Chrome extension for?

It lets your agent sign in to Chrome, Brave, Edge, Arc or Chromium without the password touching the agent’s own tool output or chat. Your agent uses it automatically when it’s available, and falls back to the CLI anywhere else.

I saved a new password. Does Agent Keyring pick it up?

Not by itself. Apple only hands passwords to another app when you start the export, so run File > Export All Items to App… again.

What about passkeys and SMS codes?

Neither. Agent Keyring handles passwords and the two-factor codes Apple Passwords generates. It can’t use passkeys or read codes sent by SMS or email.
